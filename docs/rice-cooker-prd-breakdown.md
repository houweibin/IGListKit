# 电饭煲设计方案拆分（执行版）

> 目标：将现有需求文档拆成可执行的“阶段-模块-任务-验收”结构，便于产品、工业设计、结构、硬件、固件与测试协同推进。

## 1. 项目拆分总览

- **P0：需求收敛与立项**（1-2 周）
- **P1：体验与工业设计定义**（2-3 周）
- **P2：功能与技术方案定义**（3-4 周）
- **P3：样机开发与联调验证**（4-6 周）
- **P4：试产准备与上市资料**（2-3 周）

---

## 2. 模块化拆分（按职责）

### M1 用户与场景模块
**目标**：确认“谁在什么场景下用，优先解决什么问题”。

**任务清单**
1. 用户分层细化：核心用户 / 次级用户画像（年龄、家庭人数、烹饪频次、价格敏感度）
2. 5 大关键场景流程图：预约晚餐、周末多人饭、早晨粥/蒸、杂粮饭、老人操作
3. 场景痛点优先级排序（P0/P1/P2）

**交付物**
- 用户画像卡（Persona）
- 场景任务流（Task Flow）
- 机会点优先级矩阵

**验收标准**
- 覆盖至少 80% 高频使用场景
- 各场景都有可量化目标（如操作步数、完成时长）

---

### M2 产品定义模块（PRD 主体）
**目标**：把需求转成可开发的功能规格。

**任务清单**
1. 核心功能规格表：精煮米饭、预约、保温、多功能菜单
2. 智能功能规格表：推荐、记忆、提示交互、App 预留
3. 异常流程定义：断电恢复、缺水提醒、内胆未放置、过热等
4. 参数边界定义：米量范围、预约时长、保温策略、时间微调范围

**交付物**
- PRD v1.0（含主流程和异常流程）
- 功能状态机图（待机→设置→加热→完成→保温）
- 文案清单（屏显/蜂鸣/指示灯）

**验收标准**
- 每个功能包含：输入条件、触发条件、输出结果、异常处理
- “首次 3 分钟上手、常用 3 步完成”在交互稿中可验证

---

### M3 工业设计与CMF模块
**目标**：确定外观语言、材质与品牌质感。

**任务清单**
1. 三方向外观草案：奶白 / 深灰 / 墨绿
2. 控件布局方案：顶部面板 vs 前置面板可用性评估
3. CMF 策略：抗指纹、耐刮、易清洁材质对比
4. 开盖与蒸汽导流安全体验评估

**交付物**
- ID 概念图 + 关键尺寸建议
- CMF 材质样板建议书
- 外观评审结论（推荐方案 + 备选）

**验收标准**
- 厨房台面视觉占用与收纳体积达标
- 关键交互区域老人可读、可按、可理解

---

### M4 结构与可清洁模块
**目标**：把“易清洁、易拆装、不烫手”落实到结构方案。

**任务清单**
1. 内胆、内盖、蒸汽阀拆装路径设计
2. 冷凝水与米汤残留路径优化
3. 防烫区域定义（开盖按钮、蒸汽出口、提手）
4. 缝隙与卫生死角控制标准制定

**交付物**
- 结构分解图（爆炸图）
- 可清洁性测试规范（单次清洗 ≤ 5 分钟）
- 关键零件寿命与可靠性计划

**验收标准**
- 主要部件无需复杂工具可拆洗
- 卫生死角数量与清洁时长满足目标

---

### M5 加热与口感算法模块
**目标**：稳定实现“多米种、多口感”煮饭效果。

**任务清单**
1. 不同米种（白米、糙米、杂粮）加热曲线定义
2. 口感档位（香软/偏硬/标准）参数标定
3. 快煮、精煮时间与口感平衡策略
4. 保温算法（普通/低温）与 12 小时口感衰减控制

**交付物**
- 烹饪曲线参数表
- 口感盲测方案与评分模型
- 保温效果测试报告

**验收标准**
- 无明显夹生、糊底
- 口感差异可被用户稳定感知

---

### M6 交互与显示模块
**目标**：保证界面简洁、信息清晰、学习成本低。

**任务清单**
1. 主界面信息架构：模式、剩余时间、保温时长
2. 三步操作流程优化：选模式→选份量/口感→开始
3. 提示系统设计：文字+灯+蜂鸣组合策略
4. 老人模式可读性验证（字号、对比度、文案长度）

**交付物**
- 交互流程图与界面稿
- 异常提示文案与音效规则
- 可用性测试报告（新手与老人样本）

**验收标准**
- 新用户 3 分钟可完成首次煮饭
- 关键任务路径 ≤ 3 步

---

### M7 智能互联预研模块（可选）
**目标**：为高配版预留蓝牙/Wi-Fi能力。

**任务清单**
1. App 功能边界定义：远程预约、状态提醒、清洁提醒
2. 连接稳定性与配网流程定义
3. 本地与远程控制冲突处理机制
4. 隐私与安全策略（设备绑定、数据最小化）

**交付物**
- 智能版功能蓝图
- 通信协议草案
- 版本差异清单（基础/标准/高配）

**验收标准**
- 功能可关闭且不影响基础离线使用
- 配网与解绑流程简单可恢复

---

### M8 安全与合规模块
**目标**：满足家电安全与可靠性要求。

**任务清单**
1. 防干烧、过热、防漏电、防烫策略闭环
2. 失效模式分析（FMEA）
3. 安规测试项清单（温升、绝缘、异常工况）
4. 蒸汽误触风险与机械防护验证

**交付物**
- 风险清单与对策矩阵
- 安规测试计划与记录模板
- 安全提示文案与标识规范

**验收标准**
- 关键风险项均有检测与拦截措施
- 样机测试无明显漏水、异响、误操作烫伤风险

---

## 3. 按版本拆分（Roadmap）

### V1.0（上市最小可用版本）
- 标准饭、快煮、粥/汤、预约、保温、基础显示
- 可拆洗内盖 + 基础安全保护
- 聚焦“好吃 + 好用 + 好清洁”

### V2.0（体验增强版本）
- 口感可调、智能记忆、高频推荐
- 保温算法升级
- 材质与外观质感升级

### V3.0（智能生态版本）
- App 互联、菜谱联动、清洁与维护提醒
- 用户习惯学习与个性化推荐

---

## 4. 里程碑与评审点（建议）

1. **MRD/PRD 评审**：需求冻结
2. **ID/结构评审**：外观与可制造性冻结
3. **EVT 样机评审**：功能可用与风险暴露
4. **DVT 评审**：稳定性、安全性、口感一致性
5. **PVT 评审**：试产与上市准备

---

## 5. 团队协作拆分（RACI 简版）

- **产品经理**：M1/M2 主责，版本规划与验收口径
- **工业设计**：M3 主责，外观+CMF
- **结构工程**：M4 主责，拆洗与防烫结构
- **硬件/固件**：M5/M6/M8 主责，加热、温控、交互、安全
- **App 团队**：M7 主责（高配版）
- **测试与质量**：全链路验证与风险闭环

---

## 6. 建议你下一步直接执行的 3 件事

1. **先冻结 V1.0 功能边界**（避免“功能过多”拖慢进度）
2. **优先搭建口感测试与清洁测试标准**（决定产品核心竞争力）
3. **并行推进 ID 与交互低保真评审**（尽早发现老人易用性问题）
